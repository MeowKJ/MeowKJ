### What I build

- **Embedded & hardware** — compact boards, sensors, firmware, and tools that shorten the path from schematic to a working prototype.
- **Developer tools** — practical utilities for flashing, serial workflows, EDA automation, routers, and local services.
- **Interactive experiments** — games, AI iteration loops, rhythm-game tools, and interfaces that make technical systems easier to explore.
